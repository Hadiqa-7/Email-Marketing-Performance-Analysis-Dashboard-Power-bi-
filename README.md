
# Email Marketing Performance

This Email Analysis Dashboard presents key email marketing performance metrics and breakdowns to help evaluate how well different campaigns, devices, and content types are performing.

### Top Summary Metrics:
- Total Campaigns.
- Bounced %.
- Conversion Rate.
- Opened %.
- CTR% (Click-Through Rate).
- Unsub% (Unsubscribe Rate).

### Breakdown Panels
1. Total Emails by Country
2. Total Emails by Device
3. Emails by Type
4. Bottom Chart: Total Emails and CTR % by Campaign Name

### Filters at the Top:

Month, Client Segment, and Device filters are available.
